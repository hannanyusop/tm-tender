# TM Tender Workspace

This repository is a tender/proposal workspace for TM’s BIG 2.0 / Falcon Innovation POC and Pilot RFP.

The `Source/` directory contains the tender source documents used to prepare, check, and complete the proposal submission. These documents cover tender instructions, submission forms, commercial pricing, technical requirements, legal terms, company declarations, financial evidence, security obligations, OSH requirements, and clarification Q&A.

## Project Purpose

The workspace supports preparation of a complete tender response, including:

- Proposal submission structure and checklist compliance.
- Commercial offer, BOQ, payment milestones, and pricing requirements.
- Technical solution design, architecture, AI methodology, integrations, scalability, KPIs, staffing, milestones, and delivery planning.
- Contractual, legal, confidentiality, integrity, anti-corruption, and related-party declarations.
- Company profile, financial strength, eligibility, and local-presence requirements.
- Information security, vendor hygiene, data handling, incident response, and business continuity requirements.
- OSH, environmental management, supplier, subcontractor, principal warranty, and undertaking obligations.

## Key Source Index

Use `Source/AGENTS.md` as the source-document index. It maps each tender topic to the correct PDF, DOCX, XLSX, or PPTX file.

Start with:

- `Source/01 Summary.md` for high-level orientation.
- Original source documents for exact wording, clauses, dates, financial details, signatory fields, and submission-critical requirements.

## Important Guidance

Do not rely only on summaries for final proposal content. For contractual, legal, commercial, pricing, or submission-critical matters, verify the exact requirement in the original tender document before using it in the final submission.
